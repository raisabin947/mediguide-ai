# MediGuide AI 🩺

AI-powered health assistant designed to improve health awareness and preventive care.

## Problem
Many people lack access to quick health guidance and basic medical awareness.

## Solution
MediGuide AI analyzes user symptoms and provides AI-generated health guidance including precautions and when to consult a doctor.

## Features
- Symptom analysis
- AI health suggestions
- Preventive care tips
- Simple web interface

## Tech Stack
- Python Flask
- HTML/CSS/JavaScript
- OpenAI API

git clone https://github.com/yourusername/mediguide-ai
